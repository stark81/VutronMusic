# 本地歌单功能实现计划（修订版）

## 需求摘要

为 VutronMusic 实现本地歌单的创建、重命名、删除、曲目增删与排序功能。基于 SQLite 持久化，重启后数据不丢失。歌单封面默认取第一首歌曲封面，空歌单使用 default-cover。

---

## 1. 架构思路

### 设计要点（对应修正意见）

1. **表名通用化**：使用 `Playlist` + `PlaylistEntry` 命名，包含 `pluginId` 字段区分来源（local / 未来其他插件），不限定为某一类插件。
2. **Store 复用**：`pluginMusic` store 已有 `userPlaylist`、`getPlaylistDetail`、`fetchPlaylistTracks`、`createPlaylist`、`deletePlaylist`、`addOrRemoveTracksToPlaylist` 等通过 `pluginMethodCall` 调用的方法。本地歌单直接实现这些插件方法，store 无需新增独立方法。
3. **适配现有架构**：本地插件（`local.js`）已具备 `userPlaylist`、`getPlaylistDetail`、`getPlaylistTracks` 方法，只是数据目前存在 PluginData JSON 中。本次将其迁移到 SQL 表，并补全缺失的 `createPlaylist`、`deletePlaylist`、`addOrRemoveTracksToPlaylist` 方法。

### 当前状态分析

| 方法 | local.js 现状 | 存储位置 | 行动 |
|------|-------------|----------|------|
| `userPlaylist` | ✅ 已实现 | PluginData JSON | 迁移到 Playlist 表 |
| `getPlaylistDetail` | ✅ 已实现 | PluginData JSON | 迁移到 PlaylistEntry 表 |
| `getPlaylistTracks` | ✅ 已实现 | PluginData JSON | 迁移到 PlaylistEntry 表 |
| `createPlaylist` | ❌ 未实现 | — | 新增 |
| `deletePlaylist` | ❌ 未实现 | — | 新增 |
| `addOrRemoveTracksToPlaylist` | ❌ 未实现 | — | 新增 |

### 数据流

```
用户操作 (LocalMusic.vue / PlaylistPage.vue)
  → pluginMusic store (fetchLikedPlaylists / getPlaylistDetail / pluginMethodCall)
    → pluginMethodCall('local', 'userPlaylist', ...)
      → local.js (Plugin Worker)
        → apis.db.get('Playlist', { pluginId: 'local' })
          → main进程 pluginDbGet('Playlist')
            → Playlist + PlaylistEntry 表
```

### 与现有在线歌单的异同

- 相同：走同一套 `pluginMethodCall` 接口、同一套 `PlaylistSchema` / `PlaylistDetailSchema` Zod 校验、同一套 store 方法
- 不同：在线歌单数据实时从远程接口获取（不落库），本地歌单数据落 SQLite `Playlist` / `PlaylistEntry` 表

### Risks (Pre-mortem)

| # | 风险 | 分类 | 缓解 |
|---|------|------|------|
| T1 | 将现有 PluginData JSON 中的歌单迁移到新表可能导致数据丢失 | Launch-Blocking | 迁移脚本读取旧 JSON 后逐条 INSERT，保留旧 JSON 字段作回滚用 |
| T2 | `deleteLocalPlaylist` IPC stub（返回 false）与新版 `deletePlaylist` 插件方法冲突 | Launch-Blocking | 保留 `deleteLocalPlaylist` stub 不动（已废弃），插件方法走独立路径 |
| T3 | `apis.db` 的 `Playlist` 路由在 `pluginDbGet/set` 中尚未定义，直接调用会返回 null | Launch-Blocking | 先实现 `pluginDbGet/set` 的 Playlist 分支，再改 local.js |

## 2. 数据库设计

### Playlist 表（通用）

```sql
CREATE TABLE IF NOT EXISTS "Playlist" (
    "id" TEXT NOT NULL,
    "pluginId" TEXT NOT NULL,
    "name" TEXT NOT NULL,
    "picUrl" TEXT NOT NULL DEFAULT '',
    "description" TEXT NOT NULL DEFAULT '',
    "sortOrder" INTEGER NOT NULL DEFAULT 0,
    "createTime" INTEGER NOT NULL,
    "updateTime" INTEGER NOT NULL,
    PRIMARY KEY (id, pluginId)
);
```

### PlaylistEntry 表（通用）

```sql
CREATE TABLE IF NOT EXISTS "PlaylistEntry" (
    "id" INTEGER PRIMARY KEY AUTOINCREMENT,
    "playlistId" TEXT NOT NULL,
    "pluginId" TEXT NOT NULL,
    "sourceContext" TEXT NOT NULL DEFAULT '{}',
    "snapshot" TEXT NOT NULL DEFAULT '{}',
    "position" INTEGER NOT NULL DEFAULT 0,
    "createTime" INTEGER NOT NULL,
    UNIQUE("playlistId", "pluginId", "sourceContext")
);
CREATE INDEX IF NOT EXISTS "idx_playlist_entry_playlist_position"
    ON "PlaylistEntry" ("playlistId", "position");
```

### DDL 注入

在 `src/public/migrations/plugin.sql` 的 `COMMIT;` 前追加上述建表语句（uncomment 并调整原有注释设计）。

### Tables 枚举

在 `src/main/db.ts` 的 `Tables` 枚举中添加：

```ts
Playlist = 'Playlist',
PlaylistEntry = 'PlaylistEntry'
```

### 与已有注释设计的差异

| 字段 | 注释版 | 新版 | 理由 |
|------|--------|------|------|
| Playlist.id | INTEGER | TEXT | 与 Track/Album/Artist 的 id 类型保持一致（UUID / hash） |
| Playlist.pluginId | TEXT NOT NULL | TEXT NOT NULL | 保持（区分歌单来源） |
| Playlist.sortOrder | 无 | 新增 | 支持歌单列表排序 |
| PlaylistEntry.playlistId | TEXT | TEXT | 与 Playlist.id 类型一致 |
| PlaylistEntry.snapshot | TEXT | TEXT | 保留（存 track 快照供离线展示） |

**步骤 1.3：拓展 pluginDbGet / pluginDbSet**

在 `src/main/dbHelpers.ts` 的 `pluginDbGet` 函数中添加 `case 'Playlist'`：

```ts
case 'Playlist': {
  const pid = params.pluginId || ''
  if (params.filter?.id) {
    // 单条 + entries
    const playlist = getPlaylistById(params.filter.id, pid)
    if (!playlist) return null
    const entries = getPlaylistEntries(params.filter.id, pid)
    return { ...playlist, entries }
  }
  return getAllPlaylists(pid)
}
```

在 `pluginDbSet` 函数中添加 `case 'Playlist'`：

```ts
case 'Playlist': {
  // value: { id, pluginId, name, description, op?, tracks?, orderedEntryIds? }
  if (value.op === 'delete') {
    deletePlaylist(value.id, value.pluginId)
  } else if (value.op === 'addTracks' && value.tracks) {
    addPlaylistEntries(value.id, value.pluginId, value.tracks)
    // 封面更新
    updatePlaylistPicUrlFromFirstTrack(value.id, value.pluginId)
  } else if (value.op === 'removeTracks' && value.trackIds) {
    removePlaylistEntries(value.id, value.pluginId, value.trackIds)
    updatePlaylistPicUrlFromFirstTrack(value.id, value.pluginId)
  } else if (value.op === 'reorder' && value.orderedEntryIds) {
    reorderPlaylistEntries(value.id, value.pluginId, value.orderedEntryIds)
  } else {
    // 创建/更新元数据
    createPlaylist(value.id, value.pluginId, value.name, value.description || '')
  }
  break
}
```

(covers: R-1, R-2, R-3)

**步骤 1.4：封面自动更新辅助函数**

```ts
function updatePlaylistPicUrlFromFirstTrack(playlistId: string, pluginId: string): void {
  const entries = getPlaylistEntries(playlistId, pluginId)
  if (!entries.length) {
    updatePlaylistPicUrl(playlistId, pluginId, '')
    return
  }
  // 取第一条 entry 的 snapshot 中的 picUrl
  const first = entries[0]
  const snap = JSON.parse(first.snapshot || '{}')
  updatePlaylistPicUrl(playlistId, pluginId, snap.picUrl || '')
}
```

(covers: R-3)

**步骤 2.4：新增 addOrRemoveTracksToPlaylist**

```js
exports.addOrRemoveTracksToPlaylist = async (params) => {
  const { op, playlist, tracks } = params
  const playlistId = playlist?.sourceContext?.id || playlist?.id
  if (!playlistId) return { code: 404 }

  if (op === 'add') {
    const entries = tracks.map((t) => ({
      trackId: t.id,
      sourceContext: JSON.stringify(t.sourceContext || {}),
      snapshot: JSON.stringify({ picUrl: t.picUrl, name: t.name, artists: t.artists })
    }))
    apis.db.set('Playlist', { id: playlistId, pluginId: 'local', op: 'addTracks', tracks: entries })
  } else if (op === 'remove' || op === 'del') {
    const trackIds = tracks.map((t) => t.id || t.trackId).filter(Boolean)
    apis.db.set('Playlist', { id: playlistId, pluginId: 'local', op: 'removeTracks', trackIds })
  }
  return { code: 200 }
}
```

(covers: R-2)
