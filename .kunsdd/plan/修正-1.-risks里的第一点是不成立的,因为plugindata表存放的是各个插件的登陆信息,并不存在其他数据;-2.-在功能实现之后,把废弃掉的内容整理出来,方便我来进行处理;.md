# 本地歌单功能实现计划（修订版）

## 需求摘要

为 VutronMusic 实现本地歌单的创建、重命名、删除、曲目增删与排序功能。基于 SQLite 持久化，重启后数据不丢失。歌单封面默认取第一首歌曲封面，空歌单使用 default-cover。

---

## 1. 架构思路

### 设计要点（对应修正意见）

1. **表名通用化**：使用 `Playlist` + `PlaylistEntry` 命名，包含 `pluginId` 字段区分来源（local / 未来其他插件），不限定为某一类插件。
2. **Store 复用**：`pluginMusic` store 已有 `fetchLikedPlaylists`（→ `userPlaylist`）、`getPlaylistDetail`（→ `getPlaylistDetail`）、`fetchPlaylistTracks`（→ `getPlaylistTracks`），以及 `createPlaylist`、`deletePlaylist`、`addOrRemoveTracksToPlaylist` 等通过 `pluginMethodCall` 调用的方法。本地歌单直接实现这些插件方法即可，store 无需新增独立方法。
3. **适配现有架构**：`PluginData` 表仅存放各插件登陆信息，不存储歌单数据。歌单从零走 `Playlist` / `PlaylistEntry` 表，无需从 PluginData 迁移。

### 当前状态


| 方法                            | local.js                              | 实现情况   |
| ----------------------------- | ------------------------------------- | ------ |
| `userPlaylist`                | 有，但读的是 `PluginData.playlists`（该字段不存在） | ❌ 实际为空 |
| `getPlaylistDetail`           | 有，但读的是 `PluginData.playlists`         | ❌ 实际为空 |
| `getPlaylistTracks`           | 有，同上                                  | ❌ 实际为空 |
| `createPlaylist`              | 无                                     | ❌      |
| `deletePlaylist`              | 无                                     | ❌      |
| `addOrRemoveTracksToPlaylist` | 无                                     | ❌      |


全部需基于 `Playlist` / `PlaylistEntry` 新表重新实现。

### 数据流

```
用户操作 (LocalMusic.vue / PlaylistPage.vue)
  → pluginMusic store (pluginMethodCall)
    → local.js (Plugin Worker)
      → apis.db.get('Playlist', { pluginId: 'local' })
        → main 进程 pluginDbGet('Playlist')
          → Playlist + PlaylistEntry 表
```

### Risks (Pre-mortem)


| #   | 风险                                                                      | 分类              | 缓解                                                                              |
| --- | ----------------------------------------------------------------------- | --------------- | ------------------------------------------------------------------------------- |

## 2. 数据库设计

### Playlist 表（通用）

```sql
CREATE TABLE IF NOT EXISTS "Playlist" (
    "id" TEXT NOT NULL,
    "pluginId" TEXT NOT NULL,
    "name" TEXT NOT NULL,
    "picUrl" TEXT NOT NULL DEFAULT '',
    "description" TEXT NOT NULL DEFAULT '',
    "sortOrder" INTEGER NOT NULL DEFAULT 0,
    "createTime" INTEGER NOT NULL,
    "updateTime" INTEGER NOT NULL,
    PRIMARY KEY (id, pluginId)
);
```

### PlaylistEntry 表（通用）

```sql
CREATE TABLE IF NOT EXISTS "PlaylistEntry" (
    "id" INTEGER PRIMARY KEY AUTOINCREMENT,
    "playlistId" TEXT NOT NULL,
    "pluginId" TEXT NOT NULL,
    "trackId" TEXT NOT NULL DEFAULT '',
    "sourceContext" TEXT NOT NULL DEFAULT '{}',
    "snapshot" TEXT NOT NULL DEFAULT '{}',
    "position" INTEGER NOT NULL DEFAULT 0,
    "createTime" INTEGER NOT NULL,
    UNIQUE("playlistId", "pluginId", "sourceContext")
);
CREATE INDEX IF NOT EXISTS "idx_playlist_entry_playlist_position"
    ON "PlaylistEntry" ("playlistId", "position");
```

### DDL 注入

在 `src/public/migrations/plugin.sql` 的 `COMMIT;` 前追加上述建表语句。不涉及旧数据迁移。

### Tables 枚举

在 `src/main/db.ts` 的 `Tables` 中添加 `Playlist` 和 `PlaylistEntry`。

**步骤 2.2：重写 getPlaylistDetail**

```js
exports.getPlaylistDetail = async (params) => {
  const { id } = params
  // 我喜欢的音乐
  if (id === '-1') {
    const allTracks = await apis.db.get('Track')
    const likedTracks = (allTracks?.songs || []).filter(t => t.liked)
    const data = formatPlaylistDetail({
      id: '-1', name: '我喜欢的音乐',
      trackCount: likedTracks.length,
      tracks: likedTracks.map(formatTrack)
    })
    return { code: 200, data }
  }
  // 普通歌单
  const result = await apis.db.get('Playlist', { filter: { id }, pluginId: 'local' })
  if (!result) return { code: 200, data: null }
  // 反查 Track 详情
  const trackIds = result.entries.map(e => e.trackId)
  if (trackIds.length) {
    const tracksResult = await apis.db.get('Track', { ids: trackIds })
    const data = formatPlaylistDetail({
      ...result, tracks: (tracksResult?.songs || []).map(formatTrack)
    })
    return { code: 200, data }
  }
  return { code: 200, data: formatPlaylistDetail(result) }
}
```

(covers: R-1, R-2)

**步骤 2.3：重写 getPlaylistTracks**

```js
exports.getPlaylistTracks = async (params) => {
  const { id } = params
  const entries = await apis.db.get('PlaylistEntry', { filter: { playlistId: id }, pluginId: 'local' })
  const trackIds = entries.map(e => e.trackId).filter(Boolean)
  if (!trackIds.length) return { code: 200, data: [], sourceContext: {} }
  const result = await apis.db.get('Track', { ids: trackIds })
  return { code: 200, data: (result?.songs || []).map(formatTrack), sourceContext: {} }
}
```

```js
exports.addOrRemoveTracksToPlaylist = async (params) => {
  const { op, playlist, tracks } = params
  const id = playlist?.sourceContext?.id || playlist?.id
  if (!id) return { code: 404 }

  if (op === 'add') {
    const entries = tracks.map(t => ({
      trackId: t.id || '',
      sourceContext: JSON.stringify(t.sourceContext || {}),
      snapshot: JSON.stringify({ picUrl: t.picUrl, name: t.name, artists: t.artists })
    }))
    await apis.db.set('Playlist', { id, pluginId: 'local', op: 'addTracks', tracks: entries })
  } else if (op === 'del' || op === 'remove') {
    const entryIds = tracks.map(t => t.entryId || t.id).filter(Boolean)
    await apis.db.set('Playlist', { id, pluginId: 'local', op: 'removeTracks', entryIds })
  }
  return { code: 200 }
}
```
