# SearchBox + CustomSelect 焦点问题修复

## 根因分析

两个 bug 源于同一个事件竞争问题。

### Bug 1: CustomSelect 下拉选择后立即收起

事件时序：
1. 用户点击 CustomSelect 的下拉选项
2. `mousedown` 事件触发 → SearchBox 的 `handleOutside`（第 97 行）先执行
3. 下拉菜单通过 `<Teleport to="body">` 渲染在 body 上，**不在 `containerRef` 内**
4. `handleOutside` 判断 `!containerRef.contains(target)` 为 true，且 `keywords` 为空
5. 直接设置 `showInput = false` → CustomSelect 被 `v-if` 卸载 → 下拉菜单消失
6. 后续的 `click` 事件无法到达选项，选择丢失

### Bug 2: 页面滚动失效

CustomSelect 在 dropdown 打开时设置 `enableScrolling = false`（第 256 行），关闭时恢复为 `true`（第 264 行）。但当 SearchBox 强制卸载 CustomSelect 时，watcher 的清理逻辑不会正确执行，`enableScrolling` 停留在 `false`，导致 `VirtualScrollNoHeight` 的 `overflowY` 被锁定为 `hidden`。

## 修复方案

### 1. CustomSelect.vue — 暴露 `isTargetInside` 方法

在 CustomSelect 中新增一个方法，判断给定 DOM 节点是否在其根元素或下拉菜单内：

```ts
const isTargetInside = (target: Node) => {
  return rootRef.value?.contains(target) || dropdownRef.value?.contains(target)
}
```

通过 `defineExpose` 暴露给父组件。

### 2. SearchBox.vue — `handleOutside` 中排除 CustomSelect 区域

- 添加 `customSelectRef` 引用 CustomSelect 组件实例
- 在 `handleOutside` 中增加判断：如果 target 在 CustomSelect 内部（包括 teleport 到 body 的下拉菜单），则不收起

```ts
const customSelectRef = ref()

const handleOutside = (e: MouseEvent) => {
  if (!containerRef.value?.contains(e.target as Node) && !keywords.value) {
    // 如果点击目标在 CustomSelect 内部（含下拉菜单），不收起
    if (customSelectRef.value?.isTargetInside(e.target as Node)) return
    showInput.value = false
    showInputWidth.value = 0
    showPadding.value = '0px'
  }
}
```

模板中给 CustomSelect 添加 ref：

```html
<CustomSelect ref="customSelectRef" v-if="showInput && options.length > 1" v-model="plugin" :options="options" />
```

## 涉及文件

- `src/renderer/components/CustomSelect.vue` — 新增 `isTargetInside` 方法 + `defineExpose`
- `src/renderer/components/SearchBox.vue` — `handleOutside` 增加 CustomSelect 判断 + 添加 ref

## 验证方式

1. `yarn dev` 启动开发模式
2. 打开有多个服务的页面（如 StreamPage），展开搜索框
3. 点击 CustomSelect 下拉 → 选择一个选项 → 确认选项保持、下拉收起
4. 在搜索框无输入时，点击下拉选项 → 确认不会意外收起搜索框
5. 下拉打开状态下，确认页面仍可正常滚动
6. 点击搜索框外部（非 CustomSelect 区域）→ 确认搜索框正常收起
