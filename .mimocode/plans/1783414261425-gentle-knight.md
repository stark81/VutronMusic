# Plan: 搜索插件选择持久化（修正版）

## 问题

当前实现中，SystemSettings.vue 的 searchPriority 变化后，SearchBox.vue 无法感知变化，因为它们之间没有共享的响应式状态。

## 解决方案

将 searchPriority 放到 Pinia settings store 中，利用响应式系统实现实时同步。

## 修改文件

### 1. `src/renderer/store/settings.ts`

在 settings store 中添加 searchPriority：

```typescript
// 在 reactive 对象中添加
const sourcePriority = reactive({
  lyric: ['self'] as string[],
  comment: ['self'] as string[],
  search: [] as string[]
})

// 添加 watch 同步到主进程
watch(
  sourcePriority,
  (value) => {
    window.mainApi?.send('set-source-priority', cloneDeep(toRaw(value)))
  },
  { deep: true }
)

// 在 onMounted 中从主进程读取初始值
onMounted(async () => {
  const res = await window.mainApi?.invoke('get-source-priority')
  if (res) {
    if (res.lyric) sourcePriority.lyric = res.lyric
    if (res.comment) sourcePriority.comment = res.comment
    if (res.search) sourcePriority.search = res.search
  }
  // ... 其他初始化
})

// 在 return 中导出
return {
  // ... 其他导出
  sourcePriority
}
```

### 2. `src/renderer/views/SystemSettings.vue`

使用 settings store 中的 sourcePriority，移除本地的 searchPriority：

```typescript
const { sourcePriority } = storeToRefs(settingsStore)

// 移除本地的 searchPriority ref
// const searchPriority = ref<{ code: string; name: string }[]>([])

// 修改 loadSourcePriority 中的搜索优先级逻辑
const searchOrder: string[] = sourcePriority.search || []
const searchItems = [...allLib]
if (services.value.some((s) => s.type === 'stream')) {
  searchItems.push({ code: STREAM_SENTINEL, name: '流媒体' })
}
searchItems.sort((a, b) => {
  const pa = searchOrder.indexOf(a.code)
  const pb = searchOrder.indexOf(b.code)
  if (pa === -1 && pb === -1) return 0
  if (pa === -1) return 1
  if (pb === -1) return -1
  return pa - pb
})
localSearchPriority.value = searchItems

// 拖拽排序变化时同步到 sourcePriority
watch(localSearchPriority, (newVal) => {
  sourcePriority.search = newVal.map((i) => i.code)
}, { deep: true })
```

### 3. `src/renderer/components/SearchBox.vue`

从 settings store 读取 searchPriority，移除本地的 searchPriority：

```typescript
import { useSettingsStore } from '../store/settings'
import { storeToRefs } from 'pinia'

const settingsStore = useSettingsStore()
const { sourcePriority } = storeToRefs(settingsStore)

// 移除本地的 searchPriority ref
// const searchPriority = ref<string[]>([])

// onMounted 中简化
onMounted(() => {
  document.addEventListener('mousedown', handleOutside)
})

// doKeydownEnter 中修改
const doKeydownEnter = () => {
  // 保存当前选择到最前面
  const currentPlugin = plugin.value
  const newPriority = [currentPlugin, ...sourcePriority.value.search.filter((p) => p !== currentPlugin)]
  sourcePriority.value.search = newPriority
  
  $emit('keydownEnter', keywords.value, plugin.value)
  // ... 其余逻辑
}
```

## 数据流

1. SystemSettings.vue 修改 localSearchPriority → watch 同步到 sourcePriority.search
2. sourcePriority.search 变化 → settings store watch 发送到主进程 electron-store
3. SearchBox.vue 直接从 sourcePriority.search 读取 → 响应式更新默认插件

## 行为变化

- 设置页面修改搜索优先级后，SearchBox 立即感知变化
- 搜索时选择的插件会实时更新到 store
