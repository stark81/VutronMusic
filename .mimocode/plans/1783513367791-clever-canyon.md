# 调整 playlistSource 结构方案

## 问题分析

当前 `PlaylistSourceInfo` 结构：

```typescript
export type PlaylistSourceInfo = {
  type: SourceType
  plugin: PluginId | 'all'
  sourceContext: Record<string, any>
}
```

核心问题：**聚合场景下丢失关键元数据**。以播放「我喜欢的音乐」为例：

1. `PlaylistPage.vue` 的 `loadLikedData()` 覆盖 `playlist.value.sourceContext` 为 `{ id: type, trackIds: [], loadedIDs: [] }`，**丢失了 `pluginType`**
2. `play()` 构建 source：`{ type: 'Playlist', plugin: 'all', sourceContext: { id: type, trackIds: [], loadedIDs: [] } }`
3. `getListSourcePath` 在 `Playlist` case 中依赖 `sourceContext.pluginType` 构建 liked-songs 路径，但 `pluginType` 已丢失
4. 没有歌单名称/封面等元数据，无法在 UI 层展示「正在播放来源」

## 调整方案

### 1. 扩展 PlaylistSourceInfo 类型

**文件**: `src/types/music.d.ts`

```typescript
export type PlaylistSourceInfo = {
  type: SourceType
  plugin: PluginId | 'all'
  sourceContext: Record<string, any>
  meta?: {
    name?: string
    picUrl?: string
    pluginType?: MusicType
  }
}
```

### 2. 修改 PlaylistPage.vue

**文件**: `src/renderer/views/PlaylistPage.vue`

- `play()` 补全 meta（name、picUrl、pluginType）
- `loadLikedData()` 保留 pluginType 在 sourceContext 中

### 3. 修改其他 replacePlaylist 调用点

| 文件 | type | 需补 meta |
|------|------|----------|
| `src/renderer/views/AlbumPage.vue:240` | Album | name, picUrl |
| `src/renderer/views/ArtistPage.vue:303` | Artist | name, picUrl |
| `src/renderer/views/DailyTracks.vue:77` | DailySongs | name |
| `src/renderer/components/DailyTracksCard.vue:71` | DailySongs | name |
| `src/renderer/components/CoverBox.vue:96` | 各类型 | 从 props 提取 |
| `src/renderer/components/VirtualTrackList.vue:302` | 各类型 | 从 props 提取 |

### 4. 修改 getListSourcePath

**文件**: `src/renderer/store/player.ts`

优先从 `meta?.pluginType` 取值，回退到 `sourceContext.pluginType`。

1. `src/types/music.d.ts`

9. `src/renderer/components/VirtualTrackList.vue`

### 间接兼容（无需修改）

- `PlayerBar.vue` / `CommonPlayer.vue` — 通过 `getListSourcePath` 间接受益
- `NextUp.vue` — 只读 `playlistSource.type`
- `reportPlayback` / 主进程 `IPCs.ts` — `sourceCtx` 是 `Record<string, any>`，自动兼容
- Pinia persist — 新字段自动持久化，已有数据读取为 `undefined`（可选链处理）
