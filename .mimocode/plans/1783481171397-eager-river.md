# Fix ColorFlow.vue 两个 Bug

## 修改文件

`src/renderer/components/ColorFlow.vue`

## Fix 1: 颜色格式问题（第45行 + 第92-95行）

**问题**：`Color.rgb(swatch.rgb).rgb().string()` 返回 `rgb(r, g, b)` 字符串，第93-95行拼接 alpha hex 后缀（`'cc'`/`'66'`/`'00'`）会产生无效值如 `rgb(26,26,46)cc`，Canvas 无法解析。

**修复**：第45行 `.string()` → `.hex()`，使颜色统一为 `#rrggbb` 格式，后续拼接 `+ 'cc'` 等可正确生成 `#rrggbbaa`。

```diff
-        colors.push(Color.rgb(swatch.rgb).rgb().string())
+        colors.push(Color.rgb(swatch.rgb).hex())
```

## Fix 2: 空跑动画循环（第101-108行 + 第121-125行）

**问题**：`animate()` 在 `playing` 为 false 时仍调用 `requestAnimationFrame(animate)`，形成空循环持续消耗 CPU。

**修复**：
1. `animate()` 中非播放时直接停止，不再递归调用自身
2. `watch(playing)` 中暂停时主动 cancel 动画帧并置 null，恢复时再启动

```diff
 const animate = () => {
-  if (!playing.value) {
-    animFrameId = requestAnimationFrame(animate)
-    return
-  }
+  if (!playing.value) return
   draw()
   animFrameId = requestAnimationFrame(animate)
 }

 watch(playing, (isPlaying) => {
-  if (isPlaying && !animFrameId) {
+  if (isPlaying) {
     animFrameId = requestAnimationFrame(animate)
+  } else if (animFrameId) {
+    cancelAnimationFrame(animFrameId)
+    animFrameId = null
   }
 })
```

## 验证

修改后执行 `yarn dev`，选择 color-flow 背景类型：
1. 播放时色块应按歌曲封面颜色动态漂移
2. 暂停时动画应完全停止（浏览器 Performance 面板无动画帧）
3. 恢复播放后动画平滑恢复
