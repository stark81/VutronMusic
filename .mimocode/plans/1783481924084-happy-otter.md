## Task 0: 修复 activeBG undefined 问题

**Covers:** 问题 #0

**Files:**
- Modify: `src/renderer/store/playerTheme.ts:215-219`

**Interfaces:**
- Consumes: `activeTheme.value.theme.backgroundSource`, `activeTheme.value.theme.activeBG`
- Produces: 安全的 `activeBG` computed 属性

**问题描述:**
PlayPage.vue 第130行报错：
```typescript
let appearance = activeBG.value.color  // activeBG.value 可能是 undefined
```

原因在 `playerTheme.ts` 第215-219行：
```typescript
const activeBG = computed(() => {
  const theme = activeTheme.value.theme
  const bg = theme.backgroundSource.find((b) => b.type === theme.activeBG)!  // 使用了 ! 非空断言
  return bg
})
```

当 `theme.backgroundSource` 中找不到 `type === theme.activeBG` 的项时，`bg` 是 `undefined`，但 `!` 断言告诉 TypeScript 它一定存在，导致运行时错误。

**修复方案:**
移除 `!` 断言，并提供默认值：

```typescript
const activeBG = computed(() => {
  const theme = activeTheme.value.theme
  const bg = theme.backgroundSource.find((b) => b.type === theme.activeBG)
  return bg ?? theme.backgroundSource[0]  // 找不到时返回第一个背景类型
})
```

- [ ] **Step 1: 修改 activeBG computed 属性**

将 `playerTheme.ts` 第215-219行替换为：
```typescript
const activeBG = computed(() => {
  const theme = activeTheme.value.theme
  const bg = theme.backgroundSource.find((b) => b.type === theme.activeBG)
  return bg ?? theme.backgroundSource[0]
})
```

- [ ] **Step 2: Commit**

```bash
git add src/renderer/store/playerTheme.ts
git commit -m "fix: activeBG 找不到时回退到默认背景类型"
```

## Task 1: 修复异步竞态条件

**Covers:** 问题 #1

**Files:**
- Modify: `src/renderer/components/ColorFlow.vue:113-116`

**Interfaces:**
- Consumes: `pic` (from player store), `extractColors()`, `initBlobs()`
- Produces: 无新接口，仅修改现有逻辑

**问题描述:**
```typescript
// 当前代码 - 存在竞态
watch(pic, async (newPic) => {
  const colors = await extractColors(newPic)
  initBlobs(colors)  // 如果 pic 又变了，这里会用过期的颜色
})
```

**修复方案:**
```typescript
let extractVersion = 0

watch(pic, async (newPic) => {
  const currentVersion = ++extractVersion
  const colors = await extractColors(newPic)
  if (currentVersion === extractVersion) {
    initBlobs(colors)
  }
})
```

- [ ] **Step 1: 添加版本号变量**

在 `let blobs: FlowBlob[] = []` 后面添加：
```typescript
let extractVersion = 0
```

- [ ] **Step 2: 修改 watch(pic) 处理函数**

将 `watch(pic, async (newPic) => { ... })` 替换为：
```typescript
watch(pic, async (newPic) => {
  const currentVersion = ++extractVersion
  const colors = await extractColors(newPic)
```

## Task 2: 修复 Canvas resize 处理

**Covers:** 问题 #2

**Files:**
- Modify: `src/renderer/components/ColorFlow.vue:107-111`

**Interfaces:**
- Consumes: `canvasRef`, `blobs`, `initBlobs()`
- Produces: 无新接口

**问题描述:**
窗口 resize 后 canvas 尺寸更新，但光斑位置可能超出边界。

**修复方案:**
```typescript
const resize = () => {
  if (!canvasRef.value) return
  canvasRef.value.width = window.innerWidth
  canvasRef.value.height = window.innerHeight
  // 如果已有光斑，将它们约束到新边界内
  if (blobs.length > 0) {
    const w = canvasRef.value.width
    const h = canvasRef.value.height
    for (const blob of blobs) {
      blob.x = Math.min(Math.max(blob.x, -blob.radius), w + blob.radius)
      blob.y = Math.min(Math.max(blob.y, -blob.radius), h + blob.radius)
      blob.radius = Math.min(w, h) * 0.4
    }
  }
}
```

## Task 3: 改进颜色提取回退逻辑

**Covers:** 问题 #4

**Files:**
- Modify: `src/renderer/components/ColorFlow.vue:48-50`

**Interfaces:**
- Consumes: 已提取的颜色数组, `props.blobCount`
- Produces: 更丰富的颜色变体

**问题描述:**
当提取颜色不足时，简单重复最后一个颜色，视觉效果单调。

**修复方案:**
```typescript
// 基于已提取颜色生成变体
const generateColorVariant = (hex: string, index: number): string => {
  try {
    const base = Color(hex)
    // 轻微调整亮度和色相
    const lightness = index % 2 === 0 ? -10 : 10
    const hueShift = (index * 30) % 360
    return base.rotate(hueShift).lighten(lightness / 100).hex()
  } catch {
    return hex
  }
}

while (colors.length < props.blobCount) {
  const baseColor = colors[colors.length - 1] || '#1a1a2e'
  colors.push(generateColorVariant(baseColor, colors.length))
}
```
