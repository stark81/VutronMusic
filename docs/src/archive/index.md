# 归档说明

> **谁该读**：想了解项目历史和设计演变的开发者。
>
> **怎么读**：按需查阅，不需要全部读完。

归档（Archive）不等于「没用的旧文档」。归档的内容记录了：

1. **项目的历史** — 我们是怎么走到现在的
2. **设计的演变** — 同一个问题，以前是怎么解决的
3. **未完成的工作** — 做过哪些尝试、为什么暂停了

归档的价值在于：**它是项目记忆的载体**。
