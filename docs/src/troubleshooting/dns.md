# DNS 与网络问题

网易云音乐的 API 在国内和国外的访问行为不同，加上部分地区的 DNS 劫持，导致「App 连不上网易云」是最常见的用户反馈之一。

## 常见问题

### 网易云登录失败 / Cookie 过期

**症状**：登录时提示「网络错误」或登录成功后很快失效。

**原因**：
- 部分地区的 DNS 被劫持，导致网易云 API 请求被重定向到错误的服务器
- 网易云 API 对频繁登录有风控策略

**解决方案**：

1. **配置 DNS**（推荐）
   - 在系统网络设置中，将 DNS 修改为 `114.114.114.114`（国内）或 `8.8.8.8`（国际）
   - 或者参考 [wiki - 账号登录](https://github.com/stark81/VutronMusic/wiki/%E8%B4%A6%E5%8F%B7%E7%99%BB%E9%99%86) 中的方法

2. **配置代理**
   - 在 VutronMusic 设置 → 代理中配置 HTTP 代理
   - 支持使用系统代理或自定义代理服务器

3. **清理 Cookie**
   - 在设置中清除已保存的登录 Cookie
   - 重新登录

### 搜索结果为空

**症状**：搜索功能正常返回，但结果为空。

**原因**：
- 网易云 API 对某些关键词返回空结果（风控）
- 插件配置的 baseUrl 不正确

**解决方案**：
- 尝试更换搜索关键词
- 检查插件设置中的 baseUrl 是否正确

### 音频缓存失败

**症状**：开启自动缓存后，缓存目录为空。

**解决方案**：
- 检查 `设置 → 缓存` 中的缓存路径是否可写
- 检查磁盘空间是否充足
- 确认缓存功能已启用
