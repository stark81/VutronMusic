# 排错指南说明

## 排错指南的产品定位

> **谁该读**：遇到问题的用户和开发者。
>
> **怎么读**：按症状匹配，每个文档列出「症状 → 原因 → 解决方案」。

排错指南的目标是：**用户遇到问题 → 打开文档 → 找到解决方案 → 问题解决**。不需要联系作者、不需要提 Issue。

| 场景     | 用户行为             | 排错指南的角色         |
| -------- | -------------------- | ---------------------- |
| 首次使用 | 安装后出现问题       | 快速排查和修复         |
| 功能异常 | 某个功能不工作了     | 检查已知问题和解决方案 |
| 环境问题 | 特定系统平台的兼容性 | 提供平台特定的配置     |
| 升级后   | 更新版本后出现问题   | 版本变更说明和迁移     |

## 排错指南的内容策略

- **问题驱动**：以用户遇到的错误/现象为入口，而不是以技术模块为入口
- **可复制**：每个解决方案都应该有明确的操作步骤
- **安全优先**：涉及账号/密码/Token 的操作要特别注明风险
