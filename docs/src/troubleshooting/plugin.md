# 插件问题

## 插件响应超时

**症状**: 提示「插件响应超时」

**原因**: 插件方法调用超过 12 秒未返回。可能原因：插件死循环、网络请求阻塞、插件代码错误。

**解决**: 检查插件代码，确保异步操作有超时兜底。如果插件需要长时间处理，考虑分批返回。

## 请求被安全策略拦截

**症状**: 提示「请求被安全策略拦截」

**原因**: 插件向未在白名单中的域名发送了 HTTP 请求。Worker 沙箱强制进行域名白名单校验。

**解决**: 在插件 `meta.domain` 中添加对应域名。参见 [插件开发入门](../spec/architecture/plugin/getting-started) 中的 `meta` 说明。

## 数据格式异常

**症状**: 提示「数据格式异常」

**原因**: 插件返回值不符合 Zod Schema 定义。框架层强制运行时校验。

**解决**: 检查插件返回值结构是否与 Zod Schema 一致。可通过 `console.log` 输出返回值对照 Schema。

## 插件加载失败

**症状**: 插件列表为空或显示「加载失败」

**原因**: 可能原因：文件路径错误、JavaScript 语法错误、`meta` 格式不正确。

**解决**:
1. 检查插件文件是否存在且语法正确
2. 确认插件注册信息（内置插件通过 `public/plugin/` 目录加载）
3. 查看日志文件：`yarn dev` 控制台或通过「打开日志文件」按钮

## 插件崩溃

**症状**: 单个插件无响应，其他功能正常

**原因**: Worker 线程中抛出未捕获异常。Worker 沙箱隔离保证主进程不受影响。

**解决**: 查看日志定位错误，修复插件代码后重启应用即可重新加载。
