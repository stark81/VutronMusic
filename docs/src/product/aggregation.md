# 多源聚合设计

## 聚合的三个层次

| 层次 | 说明 | 例子 |
|------|------|------|
| **搜索聚合** | 同一关键词在不同平台的结果并列展示 | 网易云+酷狗+本地同时返回结果，标记来源 |
| **元数据聚合** | 一首歌的播放、歌词、评论可来自不同平台 | 播放从 A 平台，歌词从 B 平台，评论从 C 平台 |
| **收藏聚合** | 不同平台的收藏统一管理 | 网易云收藏 + 酷狗收藏在同一个界面 |

## 匹配流程

```
播放一首歌
  ├─ 查询 TrackSource → 已有匹配 → 直接使用
  └─ 无匹配 → 遍历已启用的 library 插件
      ├─ 调用 matchTrack(name, artists, duration)
      ├─ 匹配成功 → 创建 TrackSource 记录
      └─ 匹配失败 → 标记为「未匹配」，不再自动尝试
```
