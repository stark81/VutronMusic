# Tray 歌词

> 技术设计见 [design.md](./design.md)，实现记录见 [dev.md](./dev.md)。

## 功能概述

在系统托盘区域展示当前播放的歌词，支持逐字高亮和滚动动画。仅支持 macOS 和 Linux。

## 用户故事

| # | 角色 | 故事 | 价值 |
| --- | --- | --- | --- |
| US-1 | macOS 用户 | 作为 macOS 用户，我希望在菜单栏看到歌词，以便我不打开播放器也能知道在唱什么 | 随时查看歌词 |
| US-2 | Linux 用户 | 作为 Linux 用户，我希望通过 GNOME Shell 扩展显示歌词，以便我获得原生桌面体验 | 原生集成 |
| US-3 | 音乐爱好者 | 作为音乐爱好者，我希望歌词有逐字高亮，以便我可以精准跟唱 | 增强体验 |

## 平台差异

| 平台      | 实现方式                | 说明                                                     |
| --------- | ----------------------- | -------------------------------------------------------- |
| **macOS** | 原生 Objective-C++ 实现 | 绕过 Electron 静态图片限制，支持真正的滚动和逐字高亮动画 |
| **Linux** | DBus 接入外部服务       | 将歌词数据发送给 GNOME Shell 扩展等第三方托盘歌词服务    |

## 验收标准

### 场景 1：macOS 托盘歌词

```mermaid
graph LR
    A[播放歌曲] --> B[获取歌词]
    B --> C[发送到原生 Tray]
    C --> D[Core Animation 渲染]
    D --> E[逐字高亮 + 滚动]
```

Given 用户在 macOS 上播放歌曲 When 歌词数据可用 Then 系统托盘应该：

- 显示当前歌词文本
- 支持逐字高亮动画
- 歌词过长时自动滚动

### 场景 2：Linux DBus 通信

```mermaid
graph LR
    A[VutronMusic] -->|UpdateLyric JSON| B[GNOME Shell 扩展]
    B -->|显示歌词| C[桌面托盘]
    D[第三方客户端] -->|订阅信号| A
```

Given 用户在 Linux 上启用了 DBus 扩展 When 歌词数据可用 Then 系统应该：

- 通过 DBus 发送歌词 JSON 给外部扩展
- 导出 DBus 接口供第三方客户端订阅

### 场景 3：歌词宽度调整

Given 用户调整 Tray 歌词宽度 When 宽度变化 Then 歌词区域应该：

- 实时更新显示宽度
- 保持歌词居中显示
- 宽度值持久化到设置

## macOS 托盘

macOS 托盘歌词使用原生 `NSStatusItem` + 自定义 `NSView`，通过 Core Animation 实现歌词渲染。支持：

- 逐字高亮动画
- 横向滚动动画
- 播放控制按钮（上一首/播放暂停/下一首/喜欢）
- 深色/浅色模式自适应

## Linux 托盘

Linux 不直接在托盘渲染歌词，而是通过 DBus 协议将歌词数据发送给外部服务（如 GNOME Shell 扩展）。同时导出 DBus 接口供第三方客户端订阅。

## Tray 设置

| 设置项       | 说明                   |
| ------------ | ---------------------- |
| 显示歌词     | 在托盘区域显示歌词文本 |
| 显示控制按钮 | 显示播放控制按钮       |
| 显示图标     | 显示应用图标           |
| 歌词宽度     | 歌词区域宽度（像素）   |
| 逐字高亮     | 启用逐字高亮动画       |
| 高亮颜色     | 逐字高亮的颜色         |

## 成功指标

| 指标            | 目标  | 衡量方式                 |
| --------------- | ----- | ------------------------ |
| macOS 渲染帧率  | 60fps | 歌词滚动动画的流畅度     |
| Linux DBus 延迟 | <50ms | 歌词发送到外部接收的时间 |
| 内存占用        | <20MB | Tray 歌词的内存使用量    |

## 不做范围

| 排除项           | 理由                            |
| ---------------- | ------------------------------- |
| Windows 托盘歌词 | Windows 托盘 API 限制，不做实现 |
| 托盘内搜索歌曲   | 超出托盘职责                    |
| 托盘内切换音源   | 通过主窗口控制                  |
