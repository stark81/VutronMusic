# 国际化 (i18n)

基于 vue-i18n 实现多语言支持，支持简体中文、繁体中文和英文。

## 初始化

配置文件位于 `src/renderer/plugins/i18n.ts`：

```ts
import { createI18n } from 'vue-i18n'
import en from '../locales/en.json'
import zh from '../locales/zh-hans.json'
import zht from '../locales/zh-hant.json'

const settings = JSON.parse(localStorage.getItem('settings') || '{}')
const language = settings?.general?.language || 'zh'

export default createI18n({
  legacy: false,        // Composition API 风格
  locale: language,
  fallbackLocale: 'en',
  globalInjection: true, // $t() 可在所有模板中使用
  messages: { en, zh, zht }
})
```

**关键点**：
- 用户语言选择存储在 `localStorage` 的 `settings.general.language` 字段
- `legacy: false` 启用 Composition API（`useI18n()`）
- 缺失的翻译 key 会回退到英文
- OSDLyric 独立窗口**不使用** i18n（歌词文本来自外部数据源）

## 语言文件

位于 `src/renderer/locales/`：

| 文件 | locale key | 行数 |
|------|-----------|------|
| `zh-hans.json` | `zh` | ~617 |
| `zh-hant.json` | `zht` | ~602 |
| `en.json` | `en` | ~603 |

## Key 组织结构

采用按功能域分层的嵌套对象：

```
nav.*           — 侧边栏/导航标签
home.*          — 首页各板块
library.*       — 音乐库（playlist, likedSongs, albums, artists, mvs, cloudDisk）
stream.*        — 流媒体页面
local.*         — 本地音乐（scan, playlist, lyrics）
login.*         — 登录/鉴权流程
settings.*      — 设置面板（general, desktop, shortcut, plugin, account）
player.*        — 播放器栏、模态框、提示、播放队列
explore.*       — 发现页（playlists, artists, charts, mv, top）
user.*          — 用户主页
search.*        — 搜索结果
toast.*         — 通知消息
next.*          — 即将播放队列
```

## 使用方式

### 在模板中

```vue
<template>
  <span>{{ $t('nav.home') }}</span>
  <span>{{ $t('settings.general.language') }}</span>
</template>
```

### 在 Composition API 中

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
const { t } = useI18n()

const label = t('player.play')
</script>
```

### 带参数的翻译

```json
// zh-hans.json
{ "login": { "needToLogin": "此操作需要登录{serviceName}账号" } }
```

```vue
<template>
  <span>{{ $t('login.needToLogin', { serviceName: '网易云' }) }}</span>
</template>
```

## 新增翻译 Key

1. 在 `zh-hans.json`、`zh-hant.json`、`en.json` 三个文件中同时添加 key，保持嵌套结构一致
2. key 命名遵循 `功能域.模块.动作` 的层级，如 `library.likedSongs.title`
3. 在模板或脚本中通过 `$t()` / `t()` 引用

## 新增语言

1. 在 `src/renderer/locales/` 下创建 `<locale-code>.json`，以 `en.json` 为模板翻译
2. 在 `src/renderer/plugins/i18n.ts` 中导入并注册：

```ts
import fr from '../locales/fr.json'
// ...
messages: { en, zh, zht, fr }
```

3. 在设置页面的语言选项中添加该语言的入口

## 注意事项

- 三个语言文件的 key 必须保持同步，缺少的 key 会回退到英文
- OSDLyric 不加载 i18n 插件，歌词文本直接使用数据源返回的原始语言
- `localStorage` 中的 `settings.general.language` 值需与 `messages` 对象中的 key 匹配（`zh` / `zht` / `en`）
